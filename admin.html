🎂 Panel de la tienda

Ingresa para editar tortas, precios, fotos y datos de la tienda.

¿Cómo obtengo la clave?
  1. En GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Generate new token, ponle un nombre y una fecha de vencimiento.
  3. En Repository access elige Only select repositories y marca solo el repositorio de la tienda.
  4. En Permissions → Contents elige Read and write.
  5. Genera el token, cópialo y pégalo aquí.
